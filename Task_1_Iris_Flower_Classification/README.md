The goal is to build a machine learning model that can classify iris flowers into different species based on their features.

##  Problem Statement
Classify iris flowers into one of the following species:
- Setosa  
- Versicolor  
- Virginica  

based on:
- Sepal Length  
- Sepal Width  
- Petal Length  
- Petal Width  

##  Dataset
The dataset is loaded from **Scikit-learn built-in dataset (Iris dataset)**.

##  Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Scikit-learn  

##  Machine Learning Model
- Algorithm Used: Random Forest Classifier  
- Train-Test Split: 80% training, 20% testing  

##  Project Workflow
1. Import libraries  
2. Load dataset  
3. Convert dataset into DataFrame  
4. Data visualization  
5. Split data into training and testing sets  
6. Train model using Random Forest Classifier  
7. Make predictions  
8. Evaluate model performance
