## Project Overview

This project is part of my **Data Science Internship at CodSoft (10 June 2026 – 10 July 2026)**.
The goal is to build a machine learning model that can predict whether a passenger survived the Titanic disaster based on passenger details and travel information.

## Problem Statement

Predict whether a passenger survived or not using the following features:
- Passenger Class
- Sex
- Age
- Number of Siblings/Spouses
- Number of Parents/Children
- Fare
- Embarked Location

Target Variable:
- Survived
  - 0 → Did not survive
  - 1 → Survived

## Dataset

The dataset used is the Titanic dataset.

It contains information about passengers such as:
- Passenger details
- Ticket information
- Family details
- Survival status
