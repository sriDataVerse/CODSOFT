# 📈 Sales Prediction - CodSoft Internship

## Project Overview

This project is part of my Data Science Internship at CodSoft (10 June 2026 – 10 July 2026). The goal of this project is to build a machine learning model that can predict sales based on advertising expenditure.

## Problem Statement

Predict product sales based on advertising investments in different platforms.

Features Used:
- TV Advertising
- Radio Advertising
- Newspaper Advertising

Target Variable:
Sales

## Dataset

The dataset used is the Advertising Sales dataset.

It contains information about:
- Advertising budget spent on TV
- Advertising budget spent on Radio
- Advertising budget spent on Newspaper
- Sales generated

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Model

Algorithm Used:
- Linear Regression

## Project Workflow

- Import required libraries
- Load Sales dataset
- Explore dataset
- Check missing values
- Perform Exploratory Data Analysis (EDA)
- Visualize feature relationships
- Split data into training and testing sets
- Train Linear Regression model
- Make predictions
- Evaluate model performance

## Results

The model successfully predicts sales using machine learning techniques.

Evaluation Metrics Used:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

Visualizations include:

This project demonstrates how machine learning regression techniques can be used to predict sales based on advertising data and understand the impact of different marketing channels.
